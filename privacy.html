隐私政策

Hermes Agent · bobbygao3010-art 的个人 Google Workspace 连接器

1. 适用范围

本政策适用于由运营者本人在其自行运行的 Hermes 助手中使用的 Google OAuth 应用「Hermes Agent」，以及本公开说明网站。该应用仅供运营者本人使用，不面向公众提供账号注册或托管服务；本政策不是 Hermes、Nous Research、Google 或任何模型服务商的官方隐私政策。

2. 访问的数据与用途

在账号持有者授权并提出相应任务后，连接器可以访问 Gmail 邮件及相关元数据、日历与事项、Drive 文件及元数据、Docs 文档、Sheets 表格，以及通讯录。数据用于完成账号持有者请求的查询、整理、起草或管理任务。发送邮件、修改、共享或删除数据需要账号持有者确认。实际访问范围取决于已授予的 OAuth 权限。

3. 存储与保留

OAuth 客户端凭据和令牌保存在运营者的 Hermes 配置环境中，不发布到本网站或公开代码仓库。任务涉及的数据可能保留在本地会话记录、日志、缓存、导出文件或运营者配置的备份中。运营者负责这些存储的访问控制和清理；本应用不承诺固定期限自动删除。

4. AI 服务与其他第三方

Hermes 使用运营者配置的 AI 模型服务。为完成用户请求的任务，所选择的 Google 数据可能作为任务上下文发送给该服务商，并受该服务商的条款、保留规则和运营者的设置约束。因此，不能把此连接器描述为“所有数据始终只在本机处理”。OAuth 密钥和令牌不应作为模型上下文发送。

运营者不销售 Google 用户数据，不将其用于广告或画像。Google API 数据不得用于训练通用 AI 或机器学习模型；运营者必须选择与此要求兼容的服务和数据控制设置。本政策不代替对第三方实际配置的核查。

对从 Google API 获得的信息的使用和转移须遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

5. 本网站的数据处理

本站为静态说明页面，不包含登录表单、数据上传表单、分析脚本或广告，不访问 Google 账号数据。托管平台仍可能按其自身政策处理访问日志等技术信息。

6. 撤销授权与删除数据

账号持有者可以在 Google 账号的第三方连接设置 中撤销此应用的权限。撤销权限会阻止后续授权访问，但不会自动删除此前的本地会话记录、缓存、备份或模型服务商已处理的数据。运营者应同时移除本地 OAuth 凭据和不再需要的记录，并依据所选服务商的控制项处理该服务商保留的数据。

运营者为 GitHub 用户 bobbygao3010-art。关于本站或此个人连接器的说明，可以通过 网站仓库的问题反馈 联系。公开反馈中不要包含密码、令牌、邮件正文或私人文件。

当应用用途、权限或数据处理方式改变时，运营者应同步更新本政策。公开网站不会因此披露任何账号数据。
