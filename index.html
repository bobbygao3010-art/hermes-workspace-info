Hermes Agent

个人 Google Workspace 连接器 · 非商业用途

本页面说明由 GitHub 用户 bobbygao3010-art 管理的个人 Google OAuth 应用「Hermes Agent」。它将账号持有者的 Google Workspace 服务连接到其自行运行的 Hermes 助手，以执行明确请求的个人任务。

用途与权限

  • Gmail：查询和阅读邮件，以及在确认后发送或管理邮件。
  • Google Calendar：查询日历，以及在确认后创建或管理日历事项。
  • Google Drive：查询文件，以及在确认后上传、下载或管理文件。
  • Google Docs 与 Sheets：读取文档和表格，以及在确认后创建或编辑。
  • Google Contacts：读取通讯录，协助用户请求的联系相关任务。

实际可用功能受 Google 授权权限与本地配置约束。授予 API 权限并不表示助手会自动执行所有可用操作；发送邮件、修改、共享或删除数据需要账号持有者确认。

个人使用说明

此连接器仅供运营者本人使用，不是供公众注册的服务。此网站只提供公开说明，不接受 Google 登录、文件上传或账号数据。页面中不存放 OAuth 密钥、令牌、邮件、通讯录或私人文件。

这是基于 Hermes 的个人配置说明，不是 Nous Research 或 Google 官方运营的应用网站，也不代表其官方隐私政策。
